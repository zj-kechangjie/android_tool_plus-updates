# AndroidADBTool · macOS 更新通道

这里仅发布 AndroidADBTool 安装包、更新说明和签名更新索引。源码在独立私密仓库维护，不在本仓库公开。

适用于 Apple 芯片 Mac（M 系列），最低构建目标 macOS 11。

## 安装与更新

1. 首次从 [Releases](https://github.com/zj-kechangjie/android_tool_plus-updates/releases) 下载 DMG，将应用拖入“应用程序”。
2. 打开工具的“设置 → 应用更新 → 检查更新”。
3. 有新版本时，在更新窗口下载，然后点击“安装并重新启动”。无需重新手工拖拽安装包。
4. 可选“自动检查新版本”，有更新时提醒，是否安装由使用者决定。

原有 1.0.8 及更早版本没有更新组件，需先手动安装一次 1.0.9 或更高版本。更新前保存编辑并结束录屏、导出和传输。

更新使用 HTTPS，安装包和更新索引均有 Ed25519 签名。签名私钥不在仓库或应用中。应用目前使用临时签名，初次安装仍遵循 macOS 的应用打开许可；不需要关闭系统安全保护。许可与第三方组件声明随应用提供。
